# Simple Alarm Clock

A little browser-based alarm clock. It shows the live time ticking away and lets you pick an hour, minute, and AM/PM to set an alarm — when the time hits, it plays a ringtone until you clear it.

## Live preview

[https://hcald91.github.io/alarm-clock/](https://hcald91.github.io/alarm-clock/)

Or clone and serve locally:

```bash
npx serve .
```

## Tech

- Vanilla JavaScript, HTML, and CSS
- Google Fonts (Poppins)
